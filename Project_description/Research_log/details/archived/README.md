# Сохранённые материалы вне основного маршрута

[Основной маршрут](../../README.md) · [Подробности действующих глав](../README.md)

Здесь сохранена **карта совместной доступности записей CO₂ и температуры**.
Она не исследует зависимость концентрации от температуры. Дальнейшая работа
по этой ветви возможна только после согласования с I.G.; её условия отбора
не ограничивают основной CO₂-анализ историческим годом.

- [Карта и результаты](archive_coverage.ipynb) · [HTML](../../output/html/archive_coverage.html).
- [Метод отбора](archive_coverage_methods.md).
- [Уточнение вывода о 13 месяцах и служебных значениях](scope_clarification.md).
- [Снимок данных](../../data/ch03/README.md).
- [Историческая версия плана до изменения структуры](plan_before_2026-09-27.md).

Файлы данных `ch03` и `ch04`, модули `chapter03.py` и `chapter04.py`
сохраняют технические имена первой версии, чтобы не нарушать происхождение
и воспроизведение. Они не задают порядок чтения. Основные главы теперь
нумеруются только 1 → 2 → 3.

[Архив августовской подгонки](august_unqualified_model.ipynb): не прошла критерии I.G.; физические выводы по ней не допускаются.
