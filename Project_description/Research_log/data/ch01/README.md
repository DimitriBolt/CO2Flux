# Снимок данных главы 1

[Оглавление исследования](../../README.md) · [Глава 1](../../01_october_2017.ipynb)

`measurements.csv` - побайтовая копия октябрьской выгрузки, полученной из Oracle
23.09.2026 и сохранённой в `sensorDB/output/`. Упакована для отчёта 24.09.2026.
Новый запрос к базе при оформлении главы не выполнялся.

Поля: `localdatetime` (местное время базы без преобразования часового пояса),
`sensorid` (994, 1010, 1026), `datavalue` (CO₂, ppm). Диапазон времени:
`2017-10-01 00:00:00 <= localdatetime < 2017-11-01 00:00:00`; `variableid=9`.
Всего 26538 строк, по 8846 на каждый датчик.

`reference_*.csv` - числовые результаты, сохранённые программой 23.09.2026.
Notebook пересчитывает их из исходных измерений и проверяет совпадение с допуском
на округление восьми десятичных знаков. Эти файлы не служат входом для подгонки.

`provenance.json` содержит параметры, коды датчиков, происхождение, контрольные
суммы всех CSV и двух расчётных модулей на момент оформления главы.

Снимок не обновляется при обычном запуске notebook. Для новой выгрузки или изменения
метода нужно записать причину, сохранить новую версию и отдельно проверить выводы.
Проверка целостности файла не является проверкой калибровки датчиков.
