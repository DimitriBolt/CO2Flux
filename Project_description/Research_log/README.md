Температурная ветвь **приостановлена**; её необходимость сначала согласую с I.G.
[Глава 3](03_archive_coverage.ipynb) — вспомогательная карта, не основание
ограничивать CO₂ одним годом. [Уточнение](details/03_scope_clarification.md).

Для колонки $v$ рассматриваю состояние
$\mathbf C_v(t)=(C_{v,D1}(t),C_{v,D2}(t),C_{v,D3}(t))$.
На первом этапе на временном интервале $W$ оцениваю

$$
\mathbf C_v\big|_W\ \longmapsto\ \lbrace A_{v,j}(W),\ \phi_{v,j}(W),\ \Delta_{v,jk}(W)\rbrace,
\qquad \Delta_{v,jk}=\frac{24}{2\pi}\mathrm{wrap}_{2\pi}(\phi_{v,k}-\phi_{v,j}).
$$

Здесь $A,\phi$ — амплитуда и фаза максимума 24-часовой гармоники;
$\mathrm{wrap}_{2\pi}$ выбирает ветвь $[-\pi,\pi)$, $\Delta$ выражена в часах.
Это **сдвиги максимумов модели**, не измеренное время переноса газа. Суточную
гармонику нельзя без проверки отождествлять с откликом на реальный полив.

**Физический вопрос:** как изменяются амплитуды, относительные фазы и задержки
и какие механизмы совместимы с этими изменениями? Один лишь масштаб времени
не доказывает химический или биологический механизм.

Исходная траектория концентраций $\mathbf C_v(t)$ находится в $\mathbb R^3$.
Для трёх осциллирующих каналов с надёжно определёнными фазами две независимые
относительные фазы задают состояние на торе $\mathbb T^2$. Это **не**
грассманиан, на котором сравнивают оптимальные подпространства развёрток
Бухштабера. Их связь ещё требуется исследовать.
