# CO₂ в LEO: цель и маршрут исследования

Dimitri Bolt · направление по идеям I.G. · **29.09.2026**

**Цель:** исследовать эволюцию сигналов и фазовых траекторий CO₂ при превращении
базальта в почву и проверить возможность разделения вклада переноса, химического
взаимодействия и биологических источников/стоков.
Разделение механизмов пока не достигнуто.

Чтобы различать механизмы, сначала нужны устойчивые изменения характеристик
CO₂ на длинном интервале; чтобы проследить изменения, сначала проверяю,
что сами характеристики определяются из исторических данных с учётом оснований допуска:

$$
\mathbf C_v(t)\ \longmapsto\ \lbrace\mathbf H_v(d),\mathbf A_v(d)\rbrace
\ \longmapsto\ \text{эволюция во времени}
\ \longmapsto\ \text{проверка механизмов}.
$$

Здесь $v$ — выбранная колонка из трёх датчиков, $d$ — календарные сутки.
$\mathbf C_v(t)$ — траектория концентраций, а не амплитуд и не фаз колебаний;
на измерениях, прошедших [диапазонный допуск I.G.](details/02_data_checks.md#ig-admission-criteria), её значения лежат в
$((0,3000]\,\mathrm{ppm})^3$.
$\mathbf H_v(d)\in\mathbb T_{24}^3$ — три времени максимумов суточной гармоники
в часах; $\mathbf A_v(d)\in([0,\infty)\,\mathrm{ppm})^3$ — три её амплитуды.
Здесь $\mathbb T_{24}$ — круговая шкала времени суток:
координаты лежат в $[0,24\,\mathrm{ч})$, а 0 и 24 ч обозначают один момент.
Период = 24 ч.
Междатчиковые сдвиги выводятся из $\mathbf H_v(d)$ и не отождествляются
со временем переноса газа. [Определения и источники](details/02_data_checks.md#daily-trajectories).

**Глава 2 завершена по критериям PLAN.md.** Для одной колонки W_R4_C-4
(D1/D2/D3: 994/1010/1026) обработан локальный архив 11.09.2013–26.09.2026:
2 613 498 исходных записей за 157 месяцев. Технически рассчитаны
суточные характеристики для 2039 дат; **на итоговых графиках — 2036 точек**
(21.09.2013–31.12.2020, с разрывами). Из них **789** рассчитаны в
исторических интервалах, которые [аудит I.G.](../Papers/LEO_CO2_sensor_audit_2026-06-30.pdf#page=21)
указывает как пригодные для всех трёх датчиков. Остальные отображаемые
результаты имеют ограниченный либо неустановленный допуск;
[точные статусы, числа и причины пропусков](details/02_data_checks.md#archive-trajectories)
сохранены в материалах главы 2. Наличие точки на графике само по себе
не доказывает научную пригодность каждого измерения или надёжность фазы.

**Следующая [глава 3](03_long_term_evolution.ipynb) — исследование длительной эволюции суточных характеристик:**
использовать характеристики из исторических интервалов, указанных
в [аудите I.G.](../Papers/LEO_CO2_sensor_audit_2026-06-30.pdf#page=21) как пригодные для этой колонки.
Основной блок — октябрь 2017 — август 2020
(783 рассчитанных суток); 6 суток сентября 2013 сохраняются отдельным
дополнительным участком, без соединения с основным блоком.
Учитывать пропуски и неопределённость надёжности фаз;
предварительные результаты не объявлять научно допущенными.
Достаточность данных для установления длительной эволюции заранее не предполагается.
Заготовка главы 3 создана; научное выполнение не начато. [Условия следующего этапа](PLAN.md#trajectories).
После её завершения обязательный метод Бухштабера (глава 4) имеет самостоятельное входное условие: пригодные временные ряды LEO. Геометрия относительных фаз перенесена в главу 5 и требует надёжных фаз. Начало любого следующего этапа требует отдельного решения Dimitri Bolt.

эта ветвь не входит в текущий маршрут и может быть возвращена только после согласования с I.G.
