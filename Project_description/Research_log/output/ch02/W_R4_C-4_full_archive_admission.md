Последний пригодный месяц позволяет установить отрицательный статус
последующих месяцев только до календарного конца аудита. Совместный допуск
отсутствует с января 2021 по май 2026 по записи Last для D2.
Для июня–сентября 2026 эта таблица не устанавливает статус.

## Почему технический календарь не равен научному допуску

Весь архив обработан одной функцией calculation_calendar, без месячного
обрезания окон: технические категории A/B/C сохраняют прежний смысл.
Техническое A означает полные временные окна и отсутствие требующих решения
повторов/постоянных участков по существующим правилам; месячные критерии I.G.
оно не вычисляет и надёжность фазы не доказывает.

В подтверждённых блоках сохранён также прежний календарь admitted_category
с его собственными границами. Техническое A у границы блока не разрешает
использование данных соседнего неподтверждённого месяца. Это различие
показано отдельно в суточной таблице; прежние B/C не переименованы в A.
Ноябрьские исключения применяются только в согласованные даты 2017 года.
Другие постоянные участки помечаются, повторы не удаляются.
