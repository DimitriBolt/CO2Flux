Целое число суток. Изменение параметров заново вычисляет Fourier-коэффициенты из встроенных средних общих 2-часовых ячеек. Пропуски сохраняются; подключения к сети не требуется.

Точки стоят в центрах окон. Оранжевый: есть флаги проверки; синий: без флагов, надёжность не оценена; красный ×: фаза не определена. Линии разорваны через границу [−180°, 180°) и отсутствующие значения.

Паспорт окна

Три циклические координаты — радианы

Пространство фаз: T³ = S¹ × S¹ × S¹. Каждая координата в радианах на ветви [−π, π). Противоположные грани куба отождествляются. Здесь показаны только точки, кодированные датой; линий через границы нет. Все точки требуют проверки.

Формулы и ограничения

В каждой полуоткрытой ячейке [s, s + 2 ч) используется среднее наблюдений канала, не исключённых на этапе технической проверки данных. В Fourier-сумму входят только общие ячейки IW с четырьмя значениями, с одинаковым набором центров для всех каналов.

x′jk = xjk − x̄j,W, где x̄j,W — среднее по общим ячейкам окна, N — их число.

Fj = (1/N) ∑k∈IW x′jk e−iω₀tk,   ω₀ = 2πf₀ = 2π рад/сутки.

Здесь f₀ = 1 цикл/сутки, ω₀ — угловая частота. Δφᵤ→ᵥ = wrap(Arg(Fᵤ conj(Fᵥ))); wrap(φ) = (φ + π) mod (2π) − π. Для временных графиков используются градусы; для 3D — радианы: φrad = φdegπ/180.

t — реальные центры ячеек в сутках от 29.04.2025 00:00:00. Временная привязка базы подтверждена. Для идеальной синусоиды задержка второго сигнала на 4 ч даёт +60°, обратный порядок −60°.

Это прямой комплексный Fourier-коэффициент, не GLS и не обычный FFT неполной сетки. Пропуски могут смещать фазу; при малом модуле коэффициента она неустойчива. Порог покрытия или амплитуды не вводился. Перекрывающиеся окна зависимы.

Менее двух общих ячеек или нулевой коэффициент дают явную неопределённость. Возможность вычислить фазу не доказывает надёжность. «Максимальный пробел» — самый длинный ряд отсутствующих общих ячеек, включая края окна.
